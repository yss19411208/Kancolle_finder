# 艦これ ドロップ検索 ⚓

艦隊これくしょんの艦娘ドロップ海域を検索できるWebアプリケーションです。

## 特徴

- **2つの検索モード** — 海域から探す / 艦名から探す
- **艦種フィルター** — 艦種セレクトで素早く絞り込み
- **改造情報表示** — 改造先艦名と必要レベルを一覧表示
- **建造レシピ表示** — レシピ・確率・試行数をソート可能なテーブルで表示
- **海域攻略ページ** — 攻略ボタンからzekamashi.netの攻略ページをアプリ内で表示
- **レスポンシブ対応** — スマホでも快適に使用可能

## 使い方

### 海域から探す

1. 海域セレクトから海域を選択
2. ノードごとのドロップ艦一覧が表示される
3. 艦名をクリックすると詳細モーダルが開く

### 艦名から探す

1. 艦種セレクトで絞り込み（任意）
2. 艦名セレクトで艦娘を選択
3. ドロップ海域・建造レシピがタブ切り替えで表示される

## ファイル構成

```
.
├── index.html               # 公開ページ
├── Drop_Data.json           # ドロップ情報とドロップ率（自動生成）
├── Build_Data.json          # 建造レシピ（自動生成）
├── Update.json              # 更新履歴（自動追記 + 管理画面で編集）
├── Normal_Drop_Ship.json    # Wiki「出撃ドロップ」の写し（判定には使わず、管理画面での照合用）
├── admin_config.json        # アップデート日時・手動の限定/常設・除外・判定期間（管理画面で編集）
├── data/                    # 艦名・マス名のマスター（自動取得のキャッシュ）
├── scripts/update.py        # 集計スクリプト
├── .github/workflows/update.yml  # 毎日の自動更新
├── admin/                   # 管理画面（自分のサーバーに置く。admin/README.md 参照）
└── image/                   # 海域マップ画像
```

## データ更新の仕組み

1. GitHub Actions が毎日 05:07〜09:07（日本時間）に毎時 1 回、 [poi-server](https://github.com/poooi/poi-server/wiki) のダンプ（`dropshiprecords` / `createshiprecords`）を取得して集計します。管理画面で設定を保存したときと、手動実行でも動きます。
2. ダンプは月初にリセットされるため、月ごとの集計結果を `state` ブランチに保存し、過去の月と合算します。ダンプ本体は保存しません。
   過去の月は `https://db.poi.moe/` のアーカイブから取り込みます（管理画面で設定した判定期間、既定 12 か月。1 回の実行で 4 か月分ずつ）。
3. 艦ID→艦名は [api_start2](https://github.com/Tibowl/api_start2)、セルID→マス名は [poi](https://github.com/poooi/poi) と [KC3改](https://github.com/KC3Kai/KC3Kai) のデータを使います。
4. **常設**は poi の記録だけで判定します。週ごとに「戦闘数 × 出る率」から出るはずの回数を出し、8 回以上出るはずの期間に 1 回も出ていなければ「出ていない」とみなします。判定期間のはじめから出続けている艦、または途中から出始めて 60 日以上続いている艦が常設です。ただし艦これ攻略Wiki「期間限定ドロップイベント」で継続中の艦は限定です。判定結果は `data/judge.json` に出し、管理画面の「常設の判定」で確認・手動修正できます。
   **限定**は常設でない艦のうち、管理画面で登録したアップデート日時（現在時刻以前で最新のもの）以降に出ている艦で、その日時以降の報告だけで秒単位で区切って集計します。
5. ドロップ率は S勝利時の「その艦のドロップ数 ÷ そのマスの S勝利数」です。S勝利でのドロップが無い場合のみ A/B 勝利を含めて計算します。

### 手元で実行する

```sh
pip install pymongo
python scripts/update.py --state-dir state
```
